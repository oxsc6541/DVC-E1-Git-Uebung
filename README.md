# Git-Übung (DVC-E1)

## Beschreibung der Aufgaben
In dieser Übung habe ich die Grundlagen von GitBash und GitHub angewendet. 
Dazu gehören das Erstellen eines Repositories, das Hinzufügen (add) und Bestätigen (commit) von Änderungen sowie das Hochladen (push) auf GitHub.

Zusätzlich habe ich Dateioperationen wie das Umbenennen (mv) und Löschen (rm) beweisbar durchgeführt.
Die "Zeitreisen" beinhalten Folgendes: Ich habe zwei Branches (A und B) erstellt, zwischen ihnen gewechselt und sie anschließend zusammengeführt (merge), wobei ich einen Merge-Konflikt erfolgreich gelöst habe.
